# 🖼️ 固件 UI 渲染图

这些图片由**固件里真实运行的同一份 C 代码**在 PC 上逐像素渲染导出（128×64 显存 → PNG，
放大 6 倍并做冷白发光效果），与硬件 OLED 上的画面几乎一致。

- 生成方法与脚本见 [`../../tools/ui_render/`](../../tools/ui_render/)
- `00_overview.png` 为全部界面总览
- `01_home_clock.png` … `16_set_time.png` 为各页面单独大图

> 真实拍摄的演示视频 / GIF 仍可直接放进 `demo/` 根目录，替换或补充这里的示意图。
